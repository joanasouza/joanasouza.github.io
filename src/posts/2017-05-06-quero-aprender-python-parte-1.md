# Quero aprender Python, mas qual o primeiro passo? Parte I

Existem várias referências e materiais na internet para aprender programação e a linguagem python em específico. No post de hoje, trouxe uma lista com alguns materiais disponíveis na internet, desde cursos à livros, para quem não tem conhecimento nenhum sobre programação e quer começar com python.

### Livros
[Pense em Python](https://www.novatec.com.br/livros/pense-em-python/): Esse livro foi escrito pelo Allen Downey e é bastante indicado pela comunidade. Você pode adquiri-lo pela editora Novatec, ou conferir a [versão online](https://penseallen.github.io/PensePython2e/).

[Introdução à programação com Python](http://www.novatec.com.br/livros/introducao-python-2ed/): O autor desse livro é o Nilo Ney Coutinho Menezes e a obra já se encontra na 2ª edição. O livro em si não tem o objetivo de ensinar a linguagem python e sim conceitos de algoritmos e programação. É um bom material para você construir e solidificar os seus conhecimentos, e a medida que você for aprendendo os tópicos, há exemplos de como os mesmos são retratados no python. O livro não só propõe teoria, mas como traz exercícios práticos.

### Documentação

A documentação além de muito importante, é uma boa fonte de consulta. Basicamente, ela tem o dever de conter todas as informações sobre a linguagem, desde um simples detalhe à algo mais complexo. Por isso uma documentação deve ser bem escrita, mas a gente não espera que você leia toda a documentação de vez, simplesmente por ser algo muito exaustivo, uma prática alternativa seria consultá-la em momentos de dúvidas.

### Cursos

[Python para zumbis](https://www.pycursos.com/python-para-zumbis/): Você provavelmente já deve ter ouvido falar sobre o Python para Zumbis. Esse curso foi desenvolvido pelo professor [Fernando Masanori](https://github.com/fmasanori), que além de ser muito ativo na comunidade é bastante acessível para tirar dúvidas e etc. Muitas pessoas da comunidade python-br começaram os seus estudos pelo Python para Zumbis, que além de ser encontrado na versão online (youtube e plataforma do pingmind), o curso já teve algumas sessões presenciais em eventos de python e computação.

A dinâmica e simplicidade do curso permite com o que aluno entenda e absorva conceitos principais não só da linguagem, mas como de programação. O curso engloba conceitos básicos da linguagem, jogos com pygame e introdução à python para web.
